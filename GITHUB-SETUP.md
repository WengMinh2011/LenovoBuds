# GitHub repository

Repository: https://github.com/WengMinh2011/LenovoBuds

The `main` branch builds a debug APK automatically when source changes are pushed. To download it:

1. Open the repository's **Actions** tab.
2. Select the latest **Build LenovoBuds APK** run.
3. Wait for the run to complete successfully.
4. Download the `LenovoBuds-debug-apk` artifact and extract `app-debug.apk`.

The artifact is a debug build for testing, not a signed Play Store release. Workflow artifacts are retained for 14 days.
