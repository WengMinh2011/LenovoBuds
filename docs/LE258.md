# LE258 device notes

## Identification

The Bluetooth name may appear as `Lenovo LE258`, but names can be changed and product labels can be reused. A name match is only a hint; it does not confirm the board revision or firmware.

## Published features

The available manual describes a low-latency gaming feature. It does not describe a companion-app connection, an app-side Game/Music switch, a vendor GATT service, or a command format. Therefore the app must not claim that the hardware mode can be changed remotely.

Reference: https://manuals.plus/ae/3256811711037133

## Current LenovoBuds support

- Experimental model-name detection for `LE258`.
- BLE scanning and visible GATT service inspection.
- Standard Battery Service reading only if the device exposes it.
- Phone-side EQ profiles and game detection.
- No verified LE258 hardware Game/Music command.

## Protocol work needed

1. Test the exact LE258 revision and record the Bluetooth name shown by Android.
2. Check whether the earbuds advertise BLE services while connected for audio.
3. If an official companion app is supplied for this exact model, confirm it actually changes the earbuds' Game/Music mode and capture only the relevant Bluetooth exchange.
4. Validate the command by switching both directions and confirming the earbud mode changes.

Do not assume a product listing's “gaming” or “low latency” label implies app control. Do not write guessed payloads to unknown characteristics.
